# Marks and photographs

North Path is an independent student project. It is not an official Miami Dade College service. Showing the supplied seal is not an endorsement.

## Seal

- Original supplied file, kept unchanged: `public/brand/mdc-seal.png` (644 by 429, white field included).
- File shown in the header and footer: `public/brand/mdc-seal-transparent.png`.
- The displayed file is the supplied seal after only the outer white field, the rectangle connected to the image edge, was made transparent. White inside the wreath and the cream ring were left. The mark was not redrawn.
- Permission and source were not independently verified. No creator, license, or public-domain status is assigned.
- An earlier horizontal logotype file remains in `public/brand/MDC-Horizontal.png` and is not the mark in the header.

## Landing background

- File in this repo: `public/images/lake-background.png`
- Supplied by the user for the landing page only. The bytes are the attached file, unmodified, 2500 by 1667 pixels.
- The page uses that file with `object-fit: cover` and no blur filter and no extra magnification.
- Permission and source were not independently verified. No creator, license, or public-domain status is assigned.
- It is not used on Describe, Discover, Directory, the catalog tester, or the earlier cybersecurity example.
- `public/images/night-background.png` and `public/images/bemdc-background.png` are earlier landing photographs and are no longer displayed.
