# Catalog data dictionary

`data/catalog/catalog.json` is catalog version 1, generated by `node scripts/ingest/build-catalog.mjs`.

| Field | Meaning |
| --- | --- |
| `id` / `planCode` | Inventory plan code, `AA-#####` for a 2024–2026 pathway, or `CE-PUBLIC-SEARCH` |
| `awardType` | Inventory award, plus `AA-PATHWAY` and `CE` |
| `unit` | `credit`, `clock`, or `unknown`. Clock programs are not converted into credits for load or price |
| `credits` / `clockHours` | Parsed from a program-sheet header when present. A clock sheet may also print a credit-hour equivalent; both are stored, and planning uses clock hours |
| `coverage` | `requirements-extracted` (3 or more course rows), `requirements-partial`, `sheet-unparsed`, `sheet-not-found`, `inventory-only`, `inventory-index-only`, `narrative-only`, `source-page-without-course-rows` |
| `editionLabel` | Inventory revision, program-sheet effective term, `2024-2026 catalog (previous edition, not 2026-2028)`, or the continuing-education check date. The app does not rewrite this label |
| `confidence` | How much of the record is a direct parse versus a layout guess. An AA title is medium only when the column text beside the code was read; otherwise the name stays unverified and confidence stays low |
| `requirements[]` | `all` (every parsed course), `choose` (OR rows or a credit minimum below the sum), or `note` |
| `requirements[].children[].prerequisite` | `course`, `and`, `or`, `test`, `permission`, or `unknown` |
| `wildcardElectives` | Prefix stars such as `COP*` copied from the sheet. They are not expanded into invented courses |
| `sources[]` | URL, title, as-of date, edition, effective term, note |
| `conflicts[]` | Disagreeing values kept side by side |
| `fees.rates` | Dollar amounts copied from the public tuition pages, with the year label printed on that page |
| `fees.schedules.sectionOfferings` | Always `unknown`. Term names are calendar shapes, not open sections |

`data/catalog/coverage-report.json` is the computed comparison of inventory rows, fetched sheets, and AA/CE records.

`data/snapshots/academic-programs-cip.txt` is the text of the official inventory PDF. `data/snapshots/sheets/*.txt` are text extracts of program-sheet PDFs. `data/snapshots/catalog-2024-2026-aa-region.txt` is only the Associate in Arts region of the 2024–2026 catalog PDF.
